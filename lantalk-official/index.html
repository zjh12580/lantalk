部署 · Deploy

选一种，三行以内起来

要数据不出内网就选局域网版；要跨网段、换机器不丢数据就选云端版。两者账号数据不互通。

01 局域网版 · 推荐自托管

一个文件，一个命令

零第三方依赖，纯 Node 原生模块跑起来。同一局域网里任意电脑和手机， 浏览器打开 http://<服务器IP>:3000 就能用，不需要装客户端。

bash · 局域网版
# 默认 3000 端口，前台运行 Ctrl+C 停止 node LanTalk.html # 换端口 / 换数据目录 PORT=8080 LANCHAT_DATA=/data/lantalk node LanTalk.html
  • ·Node.js 16+，无需 npm install
  • ·数据在 data/，备份就是拷目录
  • ·提供 systemd 自启与防火墙放行说明
先在线看看云端版
02 云端版 · 有网就能用

邮箱登录，数据不丢

数据落在云端 Postgres 加对象存储，6 张表全部开启行级安全。 换机器、重装系统都只是重新登录一次，历史消息始终在。

身份 邮箱登录（验证码 / 密码）
实时性 轮询拉取，约 2.5 秒一轮
适用范围 有网就能用，可跨网段、跨机器
附件 存对象存储，展示时换取 10 分钟有效的签名 URL
新版（最新改动） 旧版（原数据）

两个环境相互独立，账号数据不互通。

常见问题 · FAQ

踩过的坑，都写在这了

同事打不开页面怎么办？
按顺序查三件事：防火墙是否放行了端口（sudo ufw allow 3000/tcp）；两台机器是否在同一网段； 在服务器本机执行 curl http://服务器IP:3000 自测能否通。 部署在 nginx 等反向代理后面时，要设 LANCHAT_TRUST_PROXY=1， 否则识别到的是代理 IP，所有人会共用同一个身份。
脚本报 bad interpreter 或者出现 ^M 是怎么回事？
从 Windows 拷过去的文件带了 CRLF 换行符。执行 sed -i 's/\r$//' start.sh stop.sh 把换行符转回 LF 即可。
怎么改自己的昵称？会不会变成第二个人？
点左上角自己的头像进「我的资料」改，或者在进入页填新昵称，两种方式都是 把原来的身份改名，不会多出一个用户。 大厅会提示「A 更名为 B」，历史消息里的名字也会一起更新。
云端版为什么不能在本地用 file:// 打开？
云端 SDK 只在应用自己的 HTTPS 域名下工作，用 file:// 或 localhost 打开会被源校验拒绝。所以云端版必须发布到线上才能真实预览—— 这也正是它和局域网版的根本差别。
跑测试报 Cannot find module 'jsdom'？
主程序是零依赖的，只有前端运行时测试需要 jsdom。 在包根目录执行一次 npm install 即可，它不会被主程序引用。
数据存在哪，怎么备份？
局域网版全部数据在 LanTalk/data/（可用 LANCHAT_DATA 改位置）， db.json 采用原子写入，掉电不会损坏，备份直接拷这个目录。 IP 与用户的对应关系在 db.json 的 ips 字段里， 删掉某个 IP 的条目，那台机器下次就会重新要求输入昵称。
