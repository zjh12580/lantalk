LanTalk GitHub

聊天，不必出内网。

LanTalk 是一条命令就能跑起来的局域网聊天服务。消息、图片与文件都留在你自己的机器上，不经过任何第三方。

开始使用 在 GitHub 上查看
$node LanTalk.html

为什么是 LanTalk

零依赖

单个 HTML 文件既是网页也是服务器。不需要安装依赖，不需要数据库，也不需要外网。

数据自持

消息与文件存在同目录的 data/ 里，原子写入不怕掉电。备份就是拷一个文件夹。

开箱即用

大厅、私聊、群聊，已读回执、@提醒、文件传输、截图粘贴发送——进来说话就行。

两种版本，按需选用

局域网版

一条命令，同网即可

在任意一台机器上运行，同一局域网内的电脑与手机打开链接就能聊。数据全部留在本机。

$node LanTalk.html
云端版

有网就能用

邮箱验证码登录，数据存在云端。跨网段、换设备都不受影响，适合不在同一个网络的成员。

打开云端版
